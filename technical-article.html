Introduction

Semantic HTML means using HTML elements according to their meaning and purpose. It helps browsers, developers, and assistive technologies understand the structure of a webpage.

Why Semantic HTML Matters

Elements such as header, nav, main, article, section, and footer describe different parts of a webpage. They make code easier to read and maintain. Semantic HTML also helps people who use screen readers navigate a website more easily.

Before and After

Before: using generic elements for everything.

<div>
    <div>My Website</div>
    <div>Welcome to my page</div>
</div>

After: using meaningful semantic elements.

<header>
    <h1>My Website</h1>
</header>
<main>
    <p>Welcome to my page</p>
</main>

Common Accessibility Problems and Fixes

1. Images without alternative text

Problem: people using screen readers may not understand what an image shows. Fix: add descriptive alt text to meaningful images.

2. Form fields without labels

Problem: users may not know what information a field requires. Fix: connect each input to a label using matching for and id attributes.

3. Poor heading structure

Problem: headings used in the wrong order can make content harder to navigate. Fix: use headings in a logical hierarchy, starting with h1 for the main title.

Conclusion

Semantic HTML and accessibility help make websites clearer and easier for more people to use. Developers should use meaningful elements, descriptive image text, properly labelled forms, and logical headings.
